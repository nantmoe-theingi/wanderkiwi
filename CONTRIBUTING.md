# Contributing to WanderKiwi

Thank you for your interest in WanderKiwi! 

Please note that this repository is maintained primarily as a **personal portfolio and demonstration project** by Nant Moe Theingi. 

## Guidelines for Reviewers & Visitors

* **Code Exploration:** Recruiters, hiring managers, and developers are welcome to explore, read, and review the source code to evaluate architectural and engineering standards.
* **Issues & Feedback:** If you spot a bug, have a suggestion, or want to provide constructive feedback, feel free to open an **Issue** in this repository.
* **Pull Requests:** Because this is a personal portfolio showcase, direct code contributions or pull requests modifying the core application source code are generally not accepted. However, discussions and suggestions via issues are always appreciated!
